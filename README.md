# CapsIndicator

**Открытая бета.** Настраиваемые оверлей-индикаторы Caps Lock, Num Lock, Scroll Lock и раскладки клавиатуры для Windows, плюс набор мелочей, которые экономят нервы при наборе текста.

> 🇬🇧 *Customizable on-screen overlay indicators for Caps Lock, Num Lock, Scroll Lock and keyboard layout on Windows — 30 animated styles, hotkeys, fixing the layout/case of selected text, Caps Lock and layout-switch locks, sounds. Open beta.*

## Возможности

- **Окна-индикаторы** для Caps Lock, Num Lock, Scroll Lock или текущей раскладки. Их сколько угодно, каждое можно перетащить и растянуть, они могут висеть поверх всех окон. Позиции, размеры и стили запоминаются.
- **30 стилей оформления**: от компактной точки и капсулы до «жидкости», неона, матрицы, осциллографа, 3D-куба и звёзд. Анимация идёт до 144 FPS.
- **Исправление выделенного текста.** Горячая клавиша переводит набранное не в той раскладке (`ghbdtn` → `привет`). Есть два режима: универсальный и «однотипный». Отдельная клавиша меняет регистр выделенного.
- **Блокировки**: можно запретить физическую клавишу Caps Lock или смену раскладки (Alt+Shift, Ctrl+Shift, Win+Пробел). Над индикатором при этом виден мини-значок блокировки.
- **Звуки** переключения, встроенные или свои файлы, с регулировкой громкости.
- **Горячие клавиши** для всех действий (все необязательные).
- Автозапуск вместе с Windows.

## Установка

1. Скачайте `CapsIndicator.exe` из [Releases](../../releases/latest).
2. Запустите **от имени администратора**: без этого Windows не даёт отслеживать клавиатуру в окнах, запущенных с повышенными правами.
3. Настройки откроются сами. Позже их можно открыть горячей клавишей или повторным запуском exe.

Настройки хранятся в `settings.cfg` рядом с exe.

Требуется Windows 10/11 и .NET Framework 4.x (уже есть в системе).

## Сборка из исходников

Нужен только .NET Framework 4 (компилятор `csc.exe` входит в Windows):

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
